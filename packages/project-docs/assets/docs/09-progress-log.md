## 4. 维护规则

每次新增记录使用：

```markdown
### YYYY-MM-DD

#### 已完成
- 记录有业务或工程意义的结果。

#### 正在进行
- 当前真实工作。

#### 问题与阻塞
- 问题、影响和当前处理。

#### 计划偏差
- 原计划、实际结果和调整。

#### 决策与引用
- 只写摘要并链接 ADR/Issue/PR/Commit。

#### 下一步
- 一至三个具体、可执行动作。
```

不要记录变量改名、普通格式化等低价值流水账；不要删除旧记录来让历史“看起来正确”。
